M57 0.6.2 fixes the initial lint blockers with documented, narrowly scoped
exceptions for Android's DNS flag annotations and configured-VPN foreground
eligibility. VPN consent is checked before foreground startup.

- Prefer the active validated physical network instead of switching DNS to the
  last network callback; clear stale network state on loss/shutdown.
- Reject DNS replies with a mismatched operation or question type.
- Explicitly exclude private settings and cached data from cloud/device transfer.
- Reuse countdown/dock drawing objects and respect Android's current text sizing.
- Add a local signed-build command that runs checks, reuses the established
  private key, verifies its certificate, and includes exact source/checksums.
- Add GitHub's “Prepare a signed release” button: choose a version and notes,
  then version-code increment, commit, tag, signing and publication run automatically.

Account recovery remains excluded. Device acceptance on Samsung M13 / One UI 6
is tracked separately. Android debug APKs and release APKs use different signing
identities; no phone installation or data was changed by this update.
