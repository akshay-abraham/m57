M57 0.6.1 fixes the hosts-list test compilation failure in the initial release
workflow. The shared JVM/Android test helper now reads UTF-8 using
`Files.readAllBytes` instead of `Files.readString`, which is absent from the
configured Android compile API.

This retains the 0.6.0 feature set, settings and signing identity. Version code
increases to 7. The new tag leaves the failed v0.6.0 tag unchanged.

The release workflow runs debug and release tests/lint, builds the signed APK,
verifies the certificate, and publishes a prerelease with corresponding source,
checksums and these notes. Successful CI and the Samsung device checklist remain
required; the compatibility fix alone does not establish device acceptance.
